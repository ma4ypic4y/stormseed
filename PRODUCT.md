# Stormseed
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and browser JavaScript, constrained by the user's explicit GitHub Pages destination. Python collects public NOAA observations in GitHub Actions. Implementation choices are delegated by the request to build and publish the complete product.

## Users
Confirmed: everyday choices and beautiful shareable result cards. Curious people making small decisions, playing games and sharing an interesting web tool.

## Product Purpose
A useful, beautiful random picker whose inputs include actual lightning observations. The initial viewport explains it in one sentence and lets a visitor generate immediately.

## Positioning
Every result mixes a public satellite lightning snapshot with fresh browser randomness and exposes the actual input provenance. No claim of certified physical entropy or worldwide satellite coverage.

## Capabilities and Constraints
A fixed 1–100 number and one six-sided die. No list choices, coin or custom range. Shareable visual result. Top navigation opens a concise explanation. English interface, public GitHub Pages hosting under ma4ypic4y, creator link https://x.com/mbor1sov. Public data, no paid API. Scheduled ingestion must expose observation age and fail honestly.

## Brand Commitments
Latest request overrides the earlier dark blue ASCII direction: completely replace the rejected background and interface. User confirmed a dark, almost black palette. Minimal, avant-garde, unconventional self-hosted typography, clean ground, expressive number and restrained generation motion. English copy stays short and natural. Wide displays must have a deliberate composition, not a tiny instrument marooned in empty space.

## Evidence on Hand
NOAA GOES GLM open observations; RANDOM.ORG atmospheric-noise prior art; NIST entropy-source requirements. No measured lower bound for lightning min-entropy exists for this pipeline.

## Product Principles
- Generate within one action.
- Explain source, age and limitations without overwhelming the homepage.
- Beauty should invite sharing; utility should bring people back.
- Never label cached data as live or pretend satellite flashes are exclusively ground strikes.
